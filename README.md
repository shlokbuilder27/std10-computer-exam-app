## 🧠 Neuroscience-Backed Learning System

This app integrates cognitive neuroscience learning principles to maximize long-term retention and rapid retrieval during exams:

1. **Active Recall & Testing Effect**:
   - Instead of passively re-reading the textbook, interactive flashcards force the hippocampus and prefrontal cortex to retrieve facts from memory before flipping.

2. **SuperMemo SM-2 Spaced Repetition**:
   - Every question dynamically tracks its **Synaptic Strength (0% to 100%)**, repetition count, and ease factor.
   - Rating buttons (`Again`, `Hard`, `Good`, `Easy`) schedule future reviews right before the synaptic trace decays (Ebbinghaus Forgetting Curve).

3. **Dual-Coding & Memory Pegs (Paivio's Theory)**:
   - Every question is equipped with a **🧠 Neuro-Mnemonic / Memory Peg** connecting technical concepts (ASCII codes, Calc formulas, HTML tags) to spatial and auditory hooks.

4. **Error-Driven Dopaminergic Plasticity & Cognitive Traps**:
   - For every question, the app explains **why distractors are tempting**, pointing out the exact cognitive bias or test-maker trap to rewire your neural pathways.

5. **Auditory Consolidation (Phonological Loop)**:
   - Click **🔊 Read Aloud** on any card or question to engage the auditory cortex using the Web Speech API.

6. **⚡ Weak Synapses Rescue Deck**:
   - Automatically isolates any question you got wrong or rated 'Again/Hard' so you can drill weak spots until achieving 100% mastery.
